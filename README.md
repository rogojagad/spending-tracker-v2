# Spending Tracker V2

## Running This Service

### With Gradle

- `./gradlew build` - Install all dependencies
- `./gradlew bootRun --system-prop spring.profiles.active=local` - Runs
  SpringBoot as local server
- `./gradlew bootJar` - Builds executable JAR
- `./gradlew ktlintCheck` - Scan any coding style violations
- `./gradlew ktlintFormat` - Fix any coding style violations `
